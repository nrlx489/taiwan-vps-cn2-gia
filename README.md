## 常见问题

**台湾VPS需要备案吗？**
不需要。台湾属于境外服务器，无需中国大陆 ICP 备案，购买后直接使用。

**如何测试延迟？**
可以在命令行使用 `ping` 命令测试服务商提供的测试 IP，也可以用 Speedtest 或 Besttrace 查看实际路由和延迟。一般建议在晚高峰时段也测一次，更能反映真实使用情况。

**台湾VPS支持 Windows 系统吗？**
支持，但建议选择 2 核 2G 及以上配置，1 核 1G 运行 Windows 体验较差。

**和香港VPS相比哪个更好？**
没有绝对答案，取决于你的目标用户在哪里。香港节点资源更丰富、选择更多；台湾节点对面向台湾本地用户或南方用户的业务有延迟优势。如果目标用户在台湾，选台湾；如果主要是大陆用户，香港和台湾延迟差距其实不大。

**DDoS 防护有吗？**
有。默认提供基础防护，选择 BGP 高防线路可获得最高 300G DDoS 防护能力，遭受攻击时自动切换。
